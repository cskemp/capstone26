# analysis code


1) `prepare_dataframe.Rmd` : (almost) empty code that your group can use to prepare your dataframe.

2) `icesnow_exploratory.Rmd`: make an exploratory plot looking at the relationship between temperature and counts for words related to ice and snow. The code in this example was mostly copied from `analysis/analyze_cases.Rmd` in the main BILA repository.

3) `icesnow_stats.Rmd` : run mixed-effects logistic regression analysis of the relationship between temperature and counts for words related to ice and snow.

4) `beta_regression.Rmd` : run beta regression analysis of the relationship between frequency and lexicalization.
